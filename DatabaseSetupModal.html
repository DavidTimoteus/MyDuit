Buat Database MyDuit

Aplikasi ini belum menemukan database Anda. Database akan dibuat sebagai 1 file Google Spreadsheet baru di Google Drive Anda sendiri.

Penting: Seluruh data keuangan Anda (transaksi, akun, utang, dll) disimpan di dalam file Spreadsheet tersebut. Jangan menghapus, memindahkan, atau mengubah nama file ini secara sembarangan di Drive Anda, karena aplikasi tidak menyimpan salinan cadangan otomatis di tempat lain.

Database Berhasil Dibuat

Database baru sudah siap di Google Drive Anda. Kalau sebelumnya Anda menggunakan spreadsheet MyDuit lama (dengan data transaksi, akun, dan utang), Anda bisa memindahkannya ke database baru ini.

Opsional: Lewati langkah ini kalau ingin mulai dari nol. Tempel URL spreadsheet lama (contoh: https://docs.google.com/spreadsheets/d/...) atau ID-nya saja pada kolom di bawah, lalu klik "Migrasi Data".
